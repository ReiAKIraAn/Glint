读英文的时候，真正卡住你的从来不是全部生词，而是「刚好高于你现在水平」的那一批。

Glint 把它们标出来，其余的一个不碰。

━━━━━━━━━━━━━━━━━━━━
三层筛子，都是减法
━━━━━━━━━━━━━━━━━━━━

• 我的水平 — 只标比你这一档更难的词（CEFR A1–C1）
• 我通过的考试 — 中考到考研选一个，该考纲及以下的词全部静音，一次顶几千次「我认识」
• 备考目标 — 只标某份考纲里的词，而且仍然要高于你的水平。两个条件取交集，不是替代

━━━━━━━━━━━━━━━━━━━━
鼠标停一下就有释义
━━━━━━━━━━━━━━━━━━━━

音标、中文释义、考试标签（四六级／考研／托福／雅思／GRE），全部来自扩展内置的本地词库。不联网、不花钱、秒回。

音标旁边还有个喇叭，点一下念给你听。用的是系统自带的语音，离线可用。

━━━━━━━━━━━━━━━━━━━━
需要的时候才叫 AI
━━━━━━━━━━━━━━━━━━━━

词典给的是所有义项，而你要的是「它在这一句里是什么意思」。

点一下卡片上那个按钮才会调用 AI，生成一次就存在本机，同一个词不会花第二次钱。

用你自己的 API Key（BYOK），在设置页里选一家服务商填上就能用，也支持任意 OpenAI 兼容接口和本机运行的模型。

━━━━━━━━━━━━━━━━━━━━
读过的词，一键进 Anki
━━━━━━━━━━━━━━━━━━━━

生成过释义的词可以整批导出成 Anki 卡片。

正面是词和音标；背面是它在那一句里的意思、英文释义、中文词典释义，以及你自己读到的那一句原文和它的翻译——例句不是词典编的，是你真的遇到过的那一句，所以你想得起来当时在读什么。

标签按等级和考纲自动分好（C1、六级、GRE……），在 Anki 侧栏里能直接筛出「只复习六级以上的」。

导入不用配置：在 Anki 里点 Import File 选中那个文件就行，牌组会自动建好。以后每次都可以整批重导，同一个词不会变成两张卡，改过的释义还会更新。

━━━━━━━━━━━━━━━━━━━━
不打扰
━━━━━━━━━━━━━━━━━━━━

• 不改页面结构 — 用 CSS Custom Highlight API 上色，不会弄坏网站的排版和交互
• 划词的时候不弹卡片 — 卡片就在光标下方，会挡住你要选的内容
• 同一个词一页只标第一次，长文章不会变成圣诞树
• 中文站、日文站自动跳过
• 代码块、输入框、页面标了非英文的区块都不碰
• 在某个网站上不想被标，工具栏弹窗里一键关掉，子域一起生效

━━━━━━━━━━━━━━━━━━━━
键盘可用
━━━━━━━━━━━━━━━━━━━━

标注是画上去的，Tab 键走不到，所以另开了一条路：

Alt+G — 跳到下一个标注的词并弹出卡片
Alt+Shift+G — 上一个
Esc — 收起

快捷键可在 chrome://extensions/shortcuts 修改。

━━━━━━━━━━━━━━━━━━━━
数据在你自己手里
━━━━━━━━━━━━━━━━━━━━

没有服务器、没有埋点、没有账号。分级、释义、音标全部在本机完成。

只有你主动点「AI 释义」时才会联网，而且只把那一句话发给你自己配置的服务商——不经过任何中间方。

设置和词表可以导出成 JSON 备份，已生成的释义还可以导出成 Anki 卡片。API Key 只存本机，不进备份。
