    备份

    导出设置、已认识的词和已生成的释义，存成一个 JSON 文件。 API Key 不在里面——那是密钥，不该躺在一个会被随手转发的文件里， 换机器请重新填一次。

    导入是合并：已认识的词取并集，同一个词的释义保留较新的那条。
